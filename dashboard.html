Migrasi Data Armada ke Supabase

Unggah seluruh unit mobil dan pengaturan stok lokal saat ini langsung ke tabel cars di Supabase dengan sekali klik.

Skrip SQL Tabel Database

Jalankan di SQL Editor Supabase untuk membuat tabel dan RLS.

Cara Setup Supabase dalam 1 Menit:

  1. Buka proyek di Supabase Dashboard.
  2. Buka menu SQL Editor > buat kueri baru (New query).
  3. Tempel skrip SQL di bawah lalu klik tombol Run.
  4. Salin URL & anon key ke form di sebelah kiri.
-- Skrip Tabel cars & RLS AutoRent
CREATE TABLE IF NOT EXISTS public.cars (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  category TEXT NOT NULL,
  price BIGINT NOT NULL,
  transmission TEXT DEFAULT 'Matic / Manual',
  capacity TEXT DEFAULT '7 Penumpang',
  stock INTEGER DEFAULT 3 CHECK (stock >= 0),
  badge TEXT DEFAULT 'Tersedia',
  image TEXT DEFAULT '',
  description TEXT DEFAULT '',
  is_custom BOOLEAN DEFAULT TRUE,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

ALTER TABLE public.cars ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Allow public read cars" 
ON public.cars FOR SELECT TO anon, authenticated USING (true);

CREATE POLICY "Allow update cars" 
ON public.cars FOR UPDATE TO anon, authenticated USING (true);

Keunggulan Mode Supabase:

  • Database Cloud Realtime: Perubahan stok mobil langsung tersinkron ke semua pengunjung di perangkat manapun.
  • Auto Fallback Offline: Jika kuota atau koneksi Supabase terputus, website otomatis menggunakan data lokal tanpa error.
